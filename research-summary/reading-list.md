# Reading List and Source Keys

Research current as of 2026-06-10. Relative dates from sources have been normalized to absolute dates where possible. Citation keys are reused across the other reports.

## Method notes

- Firecrawl CLI was installed but was not authenticated in this unattended environment, and no Firecrawl MCP tools were configured. Research proceeded with the available web search/fetch tools.
- Repository metrics were checked with the GitHub API on 2026-06-10. Stars and issue counts are volatile.
- Some requested sources are paywalled or indirect. Where a primary source could not be confirmed, the limitation is called out below and in the relevant report.
