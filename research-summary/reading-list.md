## Notes on source quality

- Primary sources were prioritized: official protocol docs, official announcements, package registries, repository READMEs, NIST, OWASP, MIT, Cornell, Harvard, GitLab, and peer-reviewed/preprint research.
- Some blog-only statistics are included because they are widely cited in industry discussions; where possible, the report labels them as practitioner or industry evidence rather than academic fact.
- GitHub web previews in the browsing tool sometimes showed zero forks; the framework tables use `gh repo view` fork counts instead.
- The current date in this environment is 2026-05-26, so relative phrases such as "this year" were converted to absolute dates or avoided.
