# Academia (Universities, Research Centers, and Scholarly Work)

Snapshot date: **March 30, 2026**

## 1) Cornell (eCornell): education pipeline from LLM basics to governance

Cornell's eCornell **Agentic AI Architecture** certificate is one of the clearest structured educational pipelines currently available. It explicitly links:

- LLM fundamentals and prompt engineering
- RAG and context engineering
- multi-agent architecture and protocols (including MCP)
- governance, risk, ethics, and organizational adoption [R27]

This is notable because it treats "agentic AI" as both a technical and governance discipline, not purely a coding skill. The sequence also directly addresses common failure modes (hallucinations, weak context quality, weak governance design). [R27]

## 2) Harvard: protocols as institutional infrastructure

Harvard's Library Innovation Lab (LIL) argues that open protocols are the strongest lens for understanding where agent ecosystems are heading. The Agent Protocols Tech Tree (APTT) presents protocols as "rough consensus and running code" style governance, analogous to internet protocol evolution. [R25]

Key claim: because agents are comparatively easy to build (LLMs + loops + tools), centralized control is weak; protocol design is likely to shape behavior at scale. [R25]

Related Harvard legal-policy analysis (JOLT) pushes a complementary governance question: whether agentic behavior online is governed mainly by platform gatekeeping or by interoperable protocol standards enabling portable identity and delegation. [R39]

## 3) MIT: capability growth vs transparency and safety gaps

MIT's 2025 AI Agent Index (and associated paper) documents 30 agentic systems and finds that capability disclosures outpace safety disclosures. [R21][R23]

From MIT's "Further Details":

- many frontier-autonomy systems disclose little to no safety evidence
- web-conduct standards for agents remain unsettled
- accountability is fragmented across model vendors, scaffolding vendors, and deployment operators [R22]

MIT Sloan's 2026 decision guidance adds an executive perspective: agentic AI progress is real, but hallucinations and prompt-injection risks materially slow safe enterprise rollout. Human-in-the-loop remains common in high-risk operations. [R24]

## 4) Broader scholarly trends (2025-2026)

Recent research has shifted from "can agents do tasks?" to "can agents do tasks safely under adversarial conditions?" Examples:

- protocol landscape and interoperability surveys (MCP/ACP/A2A/ANP) [R44]
- indirect prompt injection red-teaming and benchmarking work [R45]
- defense work such as MELON that tries to retain utility while improving attack resistance [R46]

The consensus is not that defenses are solved. The consensus is that security robustness is currently highly environment-dependent and architecture-dependent.

## 5) Paywall and availability note

Harvard Business Review has relevant 2025 articles on governance and trust, but most content is paywalled. Where possible, this report relies on primary open documentation and publicly accessible technical papers. [R28][R29]

## Quick takeaways for practitioners

1. University material is converging on the same model: **agents require both systems design and governance design**. [R27][R24]  
2. Protocol literacy is becoming essential infrastructure knowledge, similar to API literacy in earlier software eras. [R25][R44]  
3. Safety evaluation transparency is still behind capability marketing and feature rollout. [R21][R22]
